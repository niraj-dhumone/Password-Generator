🔐 Password Generator Using Python

A simple and beginner-friendly **Password Generator** built using Python.  
This project generates a random password based on the number of **letters, symbols, and numbers** entered by the user.


🚀 Features

- 🔤 Generates random uppercase and lowercase letters
- 🔢 Generates random numbers
- 🔣 Generates random symbols
- 🔀 Randomly shuffles all selected characters
- 🔒 Creates a different password each time
- ⌨️ User can choose the number of letters, symbols, and numbers


🛠️ Technologies Used

- random module
- Lists
- for loops
- input()
- if/else concepts
- random.choice()
- random.shuffle()
- String concatenation
- f-strings

💻 How It Works

The program asks the user three questions:

1. 🔤 How many letters should the password contain?
2. 🔣 How many symbols should the password contain?
3. 🔢 How many numbers should the password contain?

The program then:

- Selects random characters from the letters, symbols, and numbers lists.
- Stores them in a password list.
- Shuffles the characters randomly.
- Combines them into one password.
- Displays the generated password.
